Información, a tu ritmo.

Refresh vuelve a leer el archivo publicado. La recopilación de noticias nuevas se realiza desde GitHub.

Cómo recopilar noticias nuevas
  1. Abre el repositorio en GitHub.
  2. Entra en Actions.
  3. Selecciona Actualizar noticias y publicar dashboard.
  4. Haz clic en Run workflow y de nuevo en Run workflow.
  5. Espera a que termine y se publique. Después pulsa Refresh.
